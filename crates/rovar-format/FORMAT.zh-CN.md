# Rovar 文件格式 1.0

[English](FORMAT.md) | 简体中文

`rovar-format` 提供分块容器，支持可定位读取、增量写入和空间整理。载荷不压缩。二进制整数均为无符号小端序；偏移量为文件内绝对位置，长度以字节计。

## 文件头

文件头占 240 字节。读取要求格式标识正确、保留字节为零、版本为 **1.0**，且存在有效提交。格式版本独立于程序版本。

| 偏移 | 长度 | 内容 |
| --- | --- | --- |
| 0 | 8 | `ROVAR\r\n\x1a` |
| 8 | 2 | 主版本：`1` |
| 10 | 2 | 次版本：`0` |
| 12 | 8 | ASCII `RVFORMAT` |
| 20 | 12 | 保留：全零 |
| 32 | 104 | 提交槽 A |
| 136 | 104 | 提交槽 B |

## 数据块与索引

不可变数据块位于文件头之后。索引使用 UTF-8 JSON 数组保存 `[key, descriptor]` 键值对，写入时按键排序。替换或删除键会更新索引；空间整理会清除无用字节。

| 描述符字段 | 类型 | 含义 |
| --- | --- | --- |
| `kind` | 字符串 | 应用定义的类型，占 1–64 个 UTF-8 字节 |
| `offset` | u64 | 数据块的绝对位置 |
| `length` | u64 | 数据块存储长度 |
| `hash` | 32 字节数组 | 数据块内容的 SHA-256 |

键占 1–1024 个 UTF-8 字节，索引上限为 64 MiB。重复键、非空数据块重叠、数据块越界或算术溢出均会被拒绝。

打开文件时读取索引，无需加载媒体载荷。`Reader::read` 读取并校验数据块；`BlockHandle::reader` 提供有边界的 `Read + Seek` 流。`copy_verified` 和 `Reader::verify` 流式校验完整数据块。局部读取不会校验整个数据块。

## 提交记录

每条记录占 104 字节，同时写入索引之后的尾部和一个文件头提交槽。

| 偏移 | 长度 | 内容 |
| --- | --- | --- |
| 0 | 8 | ASCII `RVCOMMIT` |
| 8 | 8 | 提交代数，从 1 开始 |
| 16 | 8 | 索引偏移 |
| 24 | 8 | 索引长度 |
| 32 | 8 | 已提交文件长度，包含尾部记录 |
| 40 | 32 | 索引字节的 SHA-256 |
| 72 | 32 | 本记录前 72 字节的 SHA-256 |

保存时持有独占写锁，依次执行：

1. 恢复最新有效提交，截去未提交的尾部数据。
2. 追加变更的数据块和索引，调用 `sync_all`。
3. 追加尾部记录，调用 `sync_all`。
4. 写入文件头的 `(generation - 1) % 2` 提交槽，调用 `sync_all`。

读取时按从新到旧的顺序检查提交槽，选择索引有效且尾部记录匹配的第一条提交。仅有尾部记录不代表提交完成。数据块校验在读取或验证时进行。

## 空间整理

空间整理会锁定源文件，将有效数据块流式复制并校验到同目录的临时文件，完成提交后通过重命名替换源文件。Unix 下还会同步父目录。已有读取器继续持有打开时的快照。整理后文件的提交代数从 1 开始。

## 文档数据

文档结构版本 **2** 在 1.0 容器内使用以下键：

| 键 | 内容 |
| --- | --- |
| `document` | 结构版本、文档 UUID、有序页面 UUID 和媒体元数据 |
| `page/<uuid>` | 页面名称、对象 ID、下一个对象 ID 和媒体引用 |
| `page/<uuid>/hierarchy` | 分组、父子关系、图层名称、顺序，以及可选的自动布局容器和对象尺寸规则 |
| `page/<uuid>/board/<id>` | 画板 |
| `page/<uuid>/shape/<id>` | 形状 |
| `page/<uuid>/text/<id>` | 文字和样式 |
| `media/<sha256>` | 各页面共享的媒体原始数据 |
| `preview` | 第一页 PNG（如有） |

对象 ID 在各页内独立。文档至少保留一页，始终使用排序后的第一页生成预览。结构版本 1 的单页文档打开为第 1 页，保存时升级为结构版本 2。

## 检查文件

```sh
cargo run --locked -p rovar-format --bin rovar-inspect -- design.rovar
cargo run --locked -p rovar-format --bin rovar-inspect -- design.rovar --verify
```

第一条命令列出索引，第二条还会校验所有有效数据块。
